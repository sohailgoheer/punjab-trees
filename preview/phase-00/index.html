One tree.
A lifetime of stories.

We're preparing a safe, cPanel-compatible home for real trees and their dated growth photos. The web, API and mobile architecture is taking shape in GitHub.

What you're seeing: a standalone static GitHub Pages status preview. This is NOT the React build, Laravel API or an operational social network. No real trees, user accounts, GPS uploads or database are running here.
